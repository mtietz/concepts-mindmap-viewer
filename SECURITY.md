# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository instead.

Include reproduction steps, affected versions or commits, and the potential impact. You should receive an initial response within seven days.

## Scope

The viewer is intended to bind to `127.0.0.1` and process trusted local `.concept` files. Running it on an externally accessible interface or opening untrusted archives is outside its intended use.
